# Lesson 05 - Switch Statement

## Topics Covered

- Basic Switch
- case
- break
- default
- Fall-through
- Multiple Cases
- Enhanced Switch
- switch vs if-else

## Key Points

- switch compares one expression.
- break stops execution.
- Without break, fall-through occurs.
- Enhanced switch uses ->.
- Use if-else for ranges.
- Use switch for fixed values.
