# Lesson 06 - Loops

## Topics Covered

- while loop
- do-while loop
- for loop
- break
- continue
- nested loops
- pattern printing

## Key Learnings

- while is used when number of iterations is unknown.
- do-while executes at least once.
- for loop is best when iterations are known.
- break exits the loop immediately.
- continue skips the current iteration.
- Outer loop controls rows.
- Inner loop controls columns.
- Pattern printing starts with observation, then algorithm, then code.

## Patterns Practiced

- Increasing Stars
- Decreasing Stars
- Right Triangle
- Number Triangle
- Reverse Number Triangle
- Repeated Number Triangle
- Character Triangle
