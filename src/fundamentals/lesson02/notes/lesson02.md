# Lesson 02 - Variables & Data Types

## Variables
- Variable is a named memory location (label) used to store data.
- Values are stored in memory, and variables reference those values.

## Primitive Data Types
- byte
- short
- int
- long
- float
- double
- char
- boolean

## Naming Conventions
- Variables → camelCase
- Classes → PascalCase
- Constants → UPPER_SNAKE_CASE
- Packages → lowercase

## Literals
- Integer Literal → 10
- Floating Literal → 10.5
- Character Literal → 'A'
- String Literal → "Anas"
- Boolean Literal → true / false
- Null Literal → null

## Type Casting
Implicit Casting
- Small → Large
- Automatic

Explicit Casting
- Large → Small
- Manual using (type)
- May cause data loss
